# 🎮 Video Game Sales Analysis — Power BI

An interactive Power BI dashboard designed to analyze global video game sales across platforms, genres, publishers, and regions.

The project focuses on turning historical video game sales data into clear, interactive business insights using Power BI.

## 📊 Project Overview

The dashboard provides an overview of video game sales performance and allows users to explore trends through interactive filters.

The analysis covers:

- Global video game sales
- Regional sales performance
- Platform performance
- Genre performance
- Publisher performance
- Top-selling games
- Sales trends over time

## 🎯 Business Questions

This project answers questions such as:

- Which platforms generate the highest global sales?
- Which video game genres perform best?
- Which publishers have the strongest sales performance?
- Which games are the top sellers?
- How do sales differ across North America, Europe, and Japan?
- How has video game sales performance changed over time?
- Which platforms and genres should receive more attention based on historical sales?

## 📌 Key KPIs

The dashboard includes:

- **Total Global Sales**
- **Total Games**
- **North America Sales**
- **Europe Sales**
- **Japan Sales**

## 📈 Dashboard Features

- Interactive KPI cards
- Sales trend by year
- Sales by platform
- Sales by genre
- Top-selling games
- Regional sales comparison
- Year slicer
- Platform slicer
- Publisher slicer
- Genre slicer

Users can combine the filters to explore specific segments of the video game market.

## 🛠️ Tools & Technologies

- **Microsoft Power BI**

## 🧮 Analysis Process

The project followed a typical Power BI analytics workflow:

1. Imported the video game sales dataset.
2. Reviewed and prepared the data in Power Query.
3. Created calculated measures using DAX.
4. Designed KPI cards and analytical visuals.
5. Added interactive slicers for exploration.
6. Built the final dashboard.
7. Interpreted the results to identify sales trends and market patterns.
